For Use in the command line type:

EXPGE
EXPORT for lines and points for GOOGLE EARTH

READKML
IMPORT KML to AutoCAD

GEPROPS
to edit the NAME and DESCRIPTION. BEFORE EXPORT entities


EXPGEAPAGALIC
when the license gives some problem, you can delete and re-register


after selecting the entities that will be exported, a dialog box will appear
asking how they should be processed the QUOTA coordinates, if they are related
the ground, whether they are absolute coordinates, or should be ignored (lines are drawn
on the soil)


Should be informed that the benchmark used in autocad (WGS84, SAD69 ...) which
are predefined in the file "expge.ini" with parameters:

"A" -> the major axis of the ellipsoid,
"Flatness" -> ... (1 / f, where f is the value that appears in the list of this file)
"Dx", "dy", "dz" -> translations of the coordinate system to convert carteziano
                    a point of a reference to another


will be asked on which hemisphere is located entities (North / South)

will also be necessary to inform on which zone you are working (in my case,
Curitiba is in zone 22, with central meridian 51W)

Note: You can choose which parameter to tell if the spindle or the central meridian
     informed if the central meridian, for use with signal NEGATIVE WEST
     and positive for EAST

If you do not know which zone or central meridian should use, click the button with
a question, it will show a world map, where you must click on the region
approximately where it should be drawn on google earth. Clicking on the drawing, it
calculates the hemisphere and the correct zone.

After all these parameters are correctly set, a file will be created
"*.KML" which is the format used in Google Earth

Each entity in AutoCad processed, has a Layer and this will be displayed on Google
Earth as a "folder" where this (s) organization (s) will be located

Exportable entities:
POINT, LINE, LWPOLYLINE, Polyline, SPLINE, CIRCLE, ARC, ELLIPSE
NEW!! : HATCH, INSERT, TEXT

The lines which are not LINE are exported as POLYGON, that is, any segment
STRAIGHT not be converted into line segments, creating vertices to mimic
this segment
