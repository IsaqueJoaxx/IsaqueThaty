Program:        Flatten v2.03

Release date:   24/10/97

Purpose:        Lightweight polyline support added.

This routine flattens 3D polylines and sets entity elevations to zero.

(I have another routine that stores the 3D data, and allows FLATTENED
entities to be FATTENED back up to their original 3D positions, which
is still being alpha tested.)
